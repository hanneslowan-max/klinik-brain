# Loop belajar agent
Disalin dari rhj-brain 12 Nov 2026 (aturan Bapak 17 & 19 Sep 2026), disesuaikan untuk klinik.

Semua agent terus belajar: tiap masalah + solusinya dicatat agar tidak mengulang analisa atau kesalahan.
- Perpustakaan: `memori/PELAJARAN.md` (append-only).
- Awal kerja: baca entri yang relevan dengan disiplinmu.
- Akhir kerja: append 1 entri `Tanggal · Masalah · Gejala · Diagnosis · Solusi · Prinsip`.
- Otomatis, tanpa minta izin tiap kali, untuk temuan penting (koreksi asumsi, temuan strategis).
- Subagent: tulis kandidat pelajaran di laporannya; agen utama yang menulis ke file (satu penulis per file).
- Baca file dulu sebelum edit. JANGAN menulis data klien di entri pelajaran (pakai kode `K-xxxx`).
