## 4. Cara ukur (ffmpeg, diuji 6 Okt 2026 pada 20 mp4)

Loudness total dan true peak (cetak I, LRA, Peak):
```
ffmpeg -hide_banner -nostats -i video.mp4 -af ebur128=peak=true:framelog=quiet -f null - 2>&1 | grep -E "I:|LRA:|Peak:"
```
RMS per detik (dB), untuk R6, R7, R8 (aresample menyamakan laju sampel):
```
ffmpeg -hide_banner -nostats -i video.mp4 -af "aresample=44100,asetnsamples=n=44100:p=0,astats=metadata=1:reset=1,ametadata=print:key=lavfi.astats.Overall.RMS_level:file=-" -f null - 2>/dev/null | grep RMS_level | sed 's/.*=//'
```
Nilai pertama = detik 0. Catatan: pengukuran memakai file akhir, bukan stem; RMS per detik tidak membedakan ucapan dari musik. Selisih ucapan vs bukan-ucapan dibaca dari daftar detik ber-ucapan (subtitle). Nilai pada file unduhan platform akan seragam di −14 LUFS karena normalisasi; ukur file kiriman Rengga, bukan file yang diunduh dari IG/TikTok.
